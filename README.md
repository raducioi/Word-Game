# 4글자 이어말하기 ⏱️

4글자 사자성어 중 **앞 2글자**만 보여주고, 참가자들이 나머지 2글자를 맞히는 **진행자(호스트)용 도우미 화면**입니다.

## 플레이
`index.html`을 브라우저로 열면 바로 사용할 수 있어요. (설치/빌드 불필요)
GitHub Pages: Settings → Pages → Branch `main` / root → `https://raducioi.github.io/Word-Game/`

## 진행 방식
- 앞 2글자와 **카운트다운(3초)**을 보여줘요. 나머지 2글자는 `?`로 가림
- 참가자들이 정답을 **소리내어** 맞혀요
- **화면을 터치**하면 정답 공개
- **다시 터치**하면 다음 문제로
- 직접 **종료**를 누를 때까지 계속 (문제 수 제한 없음)
- 마우스 대신 **스페이스/엔터** 키로도 진행 가능

## 커스터마이징
- 카운트다운 시간: `index.html`의 `TIME_LIMIT` 값 변경
- 단어 추가: `WORDS` 배열에 `{ w: "단어", h: "뜻" }` 추가
