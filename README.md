# 한글 게임 모음 🎮

진행자(호스트)가 화면을 보여주고 참가자들이 맞히는 한글 퀴즈 게임 모음입니다.
설치/빌드 없이 정적 HTML로 동작해요.

## 구성
```
index.html          메인 — 게임 선택
games/word.html     4글자 이어말하기 (사자성어·유행어, 3초)
games/chosung.html  초성 퀴즈 (속담·영화·드라마, 타이머 없음)
games/person.html   인물 퀴즈 (위키백과 사진, 3초)
style.css           공통 테마
sound.js            공통 사운드 (초침·팡파레)
```

## 플레이
`index.html`을 브라우저로 열면 바로 사용할 수 있어요.
GitHub Pages: Settings → Pages → Branch `main` / root → `https://raducioi.github.io/Word-Game/`

## 게임 소개
### 🀄 4글자 이어말하기
앞 2글자와 카운트다운(3초)을 보여주고, 나머지 2글자를 맞혀요. 화면 터치로 정답 공개 → 다음 문제.

### 🔠 초성 퀴즈
한글 문장의 초성만 보여줘요 (예: ㄱㅅㅊ → 기생충). 속담·영화·드라마 제목 등이 출제돼요. 타이머 없음.

### 👤 인물 퀴즈
인물 사진을 보고 3초 안에 누구인지 맞혀요. 사진은 **한국어 위키백과 요약 API**에서 실시간으로 불러오므로 **인터넷 연결이 필요**합니다. (위키미디어 이미지라 라이선스·핫링크 안전)

## 공통 조작
- 화면 **터치**(또는 스페이스/엔터)로 정답 공개 → 다시 터치로 다음 문제
- **종료** 버튼을 누를 때까지 계속 (문제 수 제한 없음)

## 커스터마이징
- 단어/문제 추가: 각 게임 HTML의 `WORDS` / `QUIZ` / `PEOPLE` 배열 수정
- 인물 추가: `{ name: "이름", wiki: "위키백과 문서 제목" }` 추가 (직접 사진을 쓰려면 `img: "URL"` 추가)
- 제한 시간: `TIME_LIMIT` 값 변경
